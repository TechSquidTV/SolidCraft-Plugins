Screws and pocketed nuts now stay attached as designs change, and extrusion rails can follow sketch paths.

## Screws

- **Screw and hole** creates native rigid joints for clearance, counterbored, countersunk and tapped placements. Moving a source sketch point moves its screw; changing a counterbore depth moves the screw with the floor.
- Tapped attachments work with layout sketches created before the solid, face-mounted sketches and placement from another active component.
- Attachments survive save/reopen and work in saved designs without the plugin installed. Identical screw definitions remain reusable across runs.
- The screw README compares the plugin with SolidCraft 0.42's built-in fasteners, including modeled threads, custom heads and drives, the combined hole workflow, and the built-in tool's preview and sizing advantages.

## Nuts and extrusions

- Nut pockets follow source sketch positions and orientation. Native joints keep pocketed nuts seated through moves and depth changes.
- Nut pocket hexes retain their alignment through large sketch moves and share one editable across-flats dimension.
- **Sketch driven** extrusions create independent rails from straight sketch lines. Rail length, position, orientation, end taps and cross-holes follow path edits; hole offsets can be measured from either end.
- Fixed-length extrusion screw holes use editable reference sketches so their access and clearance cuts move together.

## Try the attachments

Download `screw-attachment-test.sc` and open it in SolidCraft 0.42.0 or newer. Gold screws sit in counterbores on the left; teal screws sit in tapped holes on the right. In **Change Parameters**, try `counterbore_x = 32 mm`, `tapped_x = 18 mm`, or `recess_depth = 6 mm`, then save and reopen. Cosmetic threads keep edits responsive. The accompanying guide lists all parameters and expected results.

## Breaking changes and migration

- Existing screw placements and pocketed nuts are not automatically attached by upgrading. Regenerate those placements to add native joints; regenerate old nut pockets to get linked geometry and the improved hex constraints. Loose **Screw only** and **Nut only** placements remain loose.
- New extrusion screw holes use per-face reference sketches and Access/Clearance extrusion features. Scripts selecting the old `Hole at` feature names must update. Existing saved rails are not migrated, and fixed-length rails are not converted into sketch-driven rails.
- A missing or ambiguous screw seat is refused instead of leaving unattached hardware.

## Installation

Download the `techsquid-<plugin>-0.2.0.zip` for each plugin you use. In SolidCraft, choose **Plugins > Install plugin…**, select the zip, and replace the installed version. All four packages use version 0.2.0; heat-set inserts have no new behavior in this release. SHA-256 checksum files accompany the packages.

## Validation

Validated with SolidCraft 0.42.0. The live test plate passed hole moves, a 4 → 6 mm recess change, a 12 → 14 mm plate-thickness change and save/reopen, checking all four joints, actual screw geometry, bore positions and plate volume. The release also runs the screw attachment regression suite, saved-example checks, Rust unit tests, formatting and native/Wasm lint checks.
