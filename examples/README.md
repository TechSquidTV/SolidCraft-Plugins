# Examples

Each example includes a saved design, a replay recipe and screenshots. Open the design in SolidCraft to inspect or edit it. The saved models already contain their generated hardware.

1. [V-slot gantry](v-slot-gantry/) — a bolted extrusion frame with a four-wheel carriage
2. [PCB enclosure](pcb-enclosure/) — heat-set inserts and recessed lid screws
3. [Editable mounting plate](editable-mounting-plate/) — screw seats and captive nuts that follow edits
4. [Sketch-driven rails](sketch-driven-rails/) — machined rails that follow changes to their paths
5. [Bearings and clutches](bearings-and-clutches/) — sourced radial bearings and editable CSK keyways
